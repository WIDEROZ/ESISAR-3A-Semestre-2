# I - Install all the repository
#### $1^{st}$ Step - Clone
##### ssh
```bash
git clone git@github.com:WIDEROZ/ESISAR-3A-Semestre-2.git
```

##### HTTPS
```bash
git clone https://github.com/WIDEROZ/ESISAR-3A-Semestre-2.git
```

#### $2^{nd}$ Step - Update submodules
```bash
cd ESISAR-3A-Semestre-2
git submodule update --init --recursive
```
