#### Définition
En temps continu :
$$\left( \Sigma_{c} \right) : \begin{cases}
\frac{dx(t)}{dt}= Ax(t) + Bu(t) &: \text{Equation d'état} \\
y(t) =Cx(t) + Du(t) &: \text{Equation de sortie}
\end{cases}$$
En temps discret :
$$\left( \Sigma_{d} \right) : \begin{cases}
x(k+1)= Ex(k) + Fu(n)& : \text{Equation d'état} \\
y(k) =Cx(n) + Du(n) &: \text{Equation de sortie}
\end{cases}$$
# Stabilité d'un système sous forme de transformation d'état
#### Théorème
Pour toute entrée $u(t)$ bornée, les états du système à temps continu : $\dot{x}(t) = Ax(t) + Bu(t)$ sont bornées ssi :
Toutes les valeurs propres réelles de $A$ sont strictement négatives.
On dit alors que le système est stable

#### Définition - Commandabilité
Un système $(\Sigma_{c})$ est commandable si quelque soit l'état initial : $x(t_{0})$, il existe une commande $u(t)$ sur un intervalle de temps fini ($t \in [t_{0}, t_{f}]$) telle que $x(t_{f}) = 0$
(de même pour le discret)

##### Crtière de commandabilité de Kalman
Le système est commandable ssi : 
$$\boxed{\mathrm{rg}(C_{c}) =n = \dim (x)}$$
$$\text{ avec : }C_{c} = \begin{pmatrix}
B&AB&A^{2}B&\dots&A^{n-1}B
\end{pmatrix}$$
(de même avec $G$ et $F$ pour ke temps discret)

#### Fonction de transfert
Comme en appliquant Laplace : 
$$pX(p) = AX(p) + BU$$
$$Y(p) = CX + DU$$
Alors, 
$$X(p) = (pI-A)^{-1} BU$$
Ainsi : 
$$\boxed{H(p) = Y(p)U^{-1}(p) = C(pI-A)B + D}$$

#### Définition - Observabilité
$(\Sigma_{d})$ est obsrvable si quel que soit l'état initial $x(k_{0})$, la mesure de la sortie : $y(k)$ sur un intervalle de temps fini : $k in [k_{0}, k_{f}]$  et la connaissance de l'entrée $u(k)$ sur ce même intervalle permet de déterminer $x(k_{0})$
(de même pour le continu)

#### Critère de Kalman
Le système est observable ssi : 
$$\boxed{\mathrm{rg}(O_{d}) = n = \dim (x)}$$
$$\text{ avec : }O_{d} = \begin{pmatrix}
C^{\top} & (CF)^{\top}& (CF^{2})^{\top}&\dots&(CF^{n-1})^{\top}
\end{pmatrix}^{\top}$$
(de même pour le temps continu avec : $C$ et $A$)

#### Définition détectabilité
Le système $(\Sigma_{d})$ est dit détectable si : 
- Il est observable
ou

#### Observateur 
$$\hat{y} = C\hat{x}$$
$$\boxed{\hat{\dot{x}} = A\hat{x} + Bu + L(y-\hat{y})}$$
($\dim(L) = \dim(x) \dim(y)$)
Erreur d'estimation : 
$$\varepsilon = x-\hat{x}$$
Equation de l'erreur d'estimation
$$\dot{\varepsilon} = (Ax(t) + Bu(t)) - (A\hat{x} + Bu + L(y-\hat{y}))$$
Ainsi, 
$$\boxed{\dot{\varepsilon} = (A-LC)\varepsilon}$$
